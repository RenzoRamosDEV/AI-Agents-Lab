# AI-Agents-Lab
Laboratorio de investigación y experimentación para probar y evaluar agentes de IA, centrado en la comprensión del contexto, el seguimiento de instrucciones y la precisión de sus respuestas.

## Filosofía

Dos principios guían todo lo que hay en este repositorio:

- **Project KISS** (*Keep It Simple*): cada pieza se mantiene tan simple como sea posible — prompts en texto plano, configuración en ficheros legibles, sin capas de abstracción ni dependencias que no aporten. Si algo se puede resolver con un fichero y un comando, se resuelve con un fichero y un comando.
- **Low Level Lab**: el objetivo es entender cómo funcionan los agentes por dentro, no solo hacer que funcionen. Se trabaja lo más cerca posible del metal — prompts, plantillas, esquemas de salida y evals construidos a mano — para que cada comportamiento observado tenga una causa que se pueda señalar.

## Alcance y licencia

Este es un **proyecto experimental de testing, análisis y estudio** — no es software de producción. Los agentes, plantillas, datos y escenarios del repositorio son ficticios y existen solo con fines de investigación y aprendizaje.
