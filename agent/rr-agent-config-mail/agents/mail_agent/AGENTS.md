# Redactor de Emails

Redacta la contestación a un email entrante. Recibe el email (remitente, asunto y cuerpo) y devuelve un borrador de respuesta en el mismo idioma, basándose en la plantilla más adecuada según quién escribe y de qué trata.

## Ejemplos de activación

- Contesta este email
- Redacta una respuesta a este correo
- Genera la contestación a este mensaje
